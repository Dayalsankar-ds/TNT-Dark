## Commands

```bash
npm run dev     # dev server (Turbopack) on :3000
npm run build   # production build; also runs full TypeScript check
npm run lint    # bare `eslint` — no path args, relies on eslint.config.mjs
```

There is no test framework installed and no test script. If tests are needed, one must be chosen and added first — do not assume Jest/Vitest/Playwright is present.

`npm run build` is the fastest way to typecheck, since `tsc` is configured `noEmit` and there is no separate typecheck script. Running it while the dev server is up can kill the dev server (both write to `.next/`); restart the dev server afterwards if it stops responding.

## Git

This project is its own git repository: `git rev-parse --show-toplevel` returns this folder. It pushes to GitHub at `https://github.com/Dayalsankar-ds/TNT-Dark.git` (`origin`), and work lands directly on `main`, which tracks `origin/main`.

- Commit or push only when the user asks.
- Stage files by explicit path rather than `git add -A` / `git add .`, so stray local files (scratch output, `.env*`) never ride along.

(Earlier this folder had no repo of its own and git resolved to a home-directory repo; that is no longer the case as of 2026-10-15.)

## Critical: never run `npm audit fix --force`

`npm audit` reports 3 vulnerabilities (`postcss`, `sharp`). Both are transitive dependencies bundled *inside* `next` itself, not direct dependencies. npm's proposed remedy is downgrading to **`next@9.3.3`**, which would destroy the project. These clear via a Next.js patch release. Leave the warning alone.

## Stack and conventions

Next.js 16.2.11 (App Router, Turbopack) · React 19.2.4 · Tailwind CSS v4 · TypeScript strict.

**Tailwind v4 has no JS config file.** The absence of `tailwind.config.ts` is correct, not an omission. Configuration lives in CSS:

- `src/app/globals.css` holds `@import "tailwindcss"` and an `@theme inline { ... }` block. Design tokens, colors, and font mappings go there.
- `postcss.config.mjs` loads `@tailwindcss/postcss`.

Do not create a `tailwind.config.ts` or install `tailwindcss-cli`/`autoprefixer`/`postcss-import`; v4 handles those internally.

**Source layout.** Scaffolded with `--src-dir`, so app code is under `src/app/`, not `app/`. The stock `README.md` is create-next-app boilerplate and refers to `app/page.tsx` — that path is wrong for this project and the README carries no other project-specific information.

**Import alias.** `@/*` maps to `./src/*`.

## Typography system

`src/app/layout.tsx` loads Geist, Geist Mono, and Open Sans via `next/font/google` as CSS variables. `globals.css` maps them in `@theme inline`: body default is Geist (`--font-sans`, applied on `body` — the old Arial hard-override was removed); sections use `font-body` (Open Sans) explicitly. Display type (`font-display`) is **Impact**, self-hosted via `next/font/local` from `src/app/fonts/Impact.ttf` (2026-07-30, replacing the prior SF Pro system stack) — commercially licensed; webfont-license coverage was confirmed with the user before embedding it. No forced font-weight override (Impact ships one static weight; forcing 700 would fake-bold it). Anton and Oswald were removed 2026-07-27 as unused; don't reintroduce them without a decision.
